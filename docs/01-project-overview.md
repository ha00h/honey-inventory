# 01. 프로젝트 개요

## 한 줄 소개

**허니 인벤토리(Honey Inventory)**는 집안 물품의 재고를 벌집처럼 예쁘게 관리하고, 구매 주기에 맞춰 꿀벌이 알려주는 Flutter 기반 홈 인벤토리 앱이다.

## 해결하려는 문제

| 문제 | 현재 상황 | 앱의 해결 |
|------|-----------|-----------|
| 재고 파악 어려움 | 냉장고·창고를 열어봐야 앎 | 벌집 한눈에 재고 확인 |
| 구매 시점 놓침 | 다 쓴 뒤에야 기억남 | 주기 기반 꿀벌 알림 |
| 장보기 목록 분산 | 메모앱, 카톡, 머릿속에 흩어짐 | 꿀단지 장바구니에 통합 |

## 핵심 컨셉: 달콤한 꿀벌의 꿀단지 채우기

꿀벌은 부지런히 꽃가루와 꿀을 모아 **육각형 벌집(Hexagon)** 칸칸마다 가득 채운다. 앱 전체가 이 은유를 따른다.

```
🐝 꿀벌 일꾼  →  사용자 (관리자)
🍯 벌집 칸    →  물품 하나 (재고 단위)
🍯 꿀 채움    →  재고량 (많을수록 가득)
🏺 꿀단지     →  장바구니
💬 "웽웽!"   →  구매 알림
```

## 핵심 가치

1. **한눈에 보이는 재고** — 육각형 그리드로 시각적 재고 파악
2. **똑똑한 구매 타이밍** — 주기 등록 + 이력 기반 추정으로 알림
3. **감성적인 UX** — 따뜻한 노란색·파스텔톤, 귀여운 꿀벌 캐릭터
4. **실용적인 장바구니** — 구매처별 그룹핑으로 효율적 장보기

## 타깃 사용자

- 1~4인 가구의 생활용품·식재료를 관리하는 사람
- 주기적으로 소모되는 물품(휴지, 세제, 생수 등)을 잊지 않고 사고 싶은 사람
- 재고 관리 앱이지만 딱딱한 스프레드시트 느낌은 싫은 사람

## 3대 핵심 기능

### 1. 재고 관리 (벌집)

- 영수증 스캔 또는 직접 입력으로 물품 등록
- 메인 화면 벌집 그리드에 물품 아이콘 표시
- 재고량에 따라 칸에 꿀이 차오르는 시각 효과

### 2. 주기별 구매 알림 (꿀벌 타이머)

- 최초 등록 시 구매 주기 설정 (예: 2주마다)
- 동일 물품 재등록 시 이전 구매 간격으로 주기 자동 추정
- 주기 도래 시 꿀벌 캐릭터 알림 ("ㅇㅇ 칸의 꿀이 말라가고 있어요! 웽웽!")

### 3. 장바구니 (꿀단지)

- 구매 예정 물품을 꿀단지에 담기
- 구매 이력이 있는 물품은 **구매처(매장)별로 그룹** 표시
- 벌집에서 바로 장바구니로 보내기 가능

## 비주얼 키워드

| 요소 | 방향 |
|------|------|
| 색상 | 따뜻한 노란색, 꿀색, 파스텔 오렌지·크림 |
| 형태 | 육각형(Hexagon) 그리드 |
| 캐릭터 | 둥글둥글한 꿀벌 일꾼 |
| 분위기 | 깔끔하고 감성적, 과하지 않은 귀여움 |
| 모션 | 꿀 출렁임, 꿀벌 날아다니기 (알림 시) |

## 성공 지표 (초기)

- 등록 물품 수 (활성 사용자당 평균 10개 이상)
- 주기 알림 → 장바구니 전환율
- 주 1회 이상 앱 오픈 (재고 확인 습관 형성)
