## 기능 요구사항

### F-01. 벌집 메인 화면

- 육각형 그리드 레이아웃으로 물품 표시
- 각 칸: 아이콘 + 물품명 + 재고 fill 레벨 (0~100%)
- 재고 부족 칸: 테두리/색상 변화 + 작은 꿀벌 배지
- 칸 탭 → 물품 상세 화면
- FAB 또는 상단 버튼 → 물품 추가

**수용 기준**
- [ ] 등록된 모든 활성 물품이 벌집에 표시된다
- [ ] 재고 0%는 빈 칸, 100%는 가득 찬 꿀 효과로 구분된다
- [ ] 재고 임계값 이하 칸이 시각적으로 강조된다

### F-02. 물품 등록 / 수정

**입력 필드 (MVP)**

| 필드 | 필수 | 설명 |
|------|------|------|
| 물품명 | O | 예: 휴지, 생수 2L |
| 카테고리 | X | 생활용품, 식료품, 위생용품 등 |
| 현재 재고량 | O | 숫자 (단위 포함 가능) |
| 단위 | O | 개, 롤, 박스, ml 등 |
| 최소 재고량 | X | 이하 시 '부족' 표시 |
| 구매 주기 | X | N일 / N주 / N개월 |
| 아이콘 | X | 프리셋 중 선택 (기본: 카테고리 아이콘) |

**수용 기준**
- [ ] 필수 필드 없이 저장 불가
- [ ] 등록 후 벌집에 즉시 반영
- [ ] 수정 시 기존 구매 이력 유지

### F-03. 재고 조정

- 상세 화면에서 +/- 버튼 또는 숫자 직접 입력
- 조정 이력 기록 (날짜, 변경량, 사유: 사용/구매/폐기)

### F-04. 구매 주기 관리

**주기 설정 방식**

1. **수동 설정** — 등록/수정 시 "N일마다 구매" 입력
2. **자동 추정** — 동일 물품명(또는 동일 ID) 재등록 시:
   - `추정 주기 = (이번 구매일 - 이전 구매일)` 의 이동 평균
   - 사용자에게 "약 N일 주기로 추정됩니다. 적용할까요?" 확인

**알림 트리거**

| 조건 | 알림 |
|------|------|
| 마지막 구매일 + 주기 ≤ 오늘 | "구매할 때가 됐어요!" |
| 재고 ≤ 최소 재고량 | "재고가 부족해요!" |
| 둘 다 해당 | 통합 알림 (우선순위: 재고 부족) |

### F-05. 장바구니 (꿀단지)

**기본 동작**
- 물품 추가 (벌집, 알림, 직접 검색)
- 수량 지정
- 구매 완료 체크 → 재고 증가 + 장바구니 제거 + 구매 이력 기록

**구매처별 그룹핑 (P1)**
- 구매 이력에 `storeName`이 있는 항목만 그룹
- 이력 없는 항목은 "구매처 미정" 섹션
- 섹션 내 정렬: 최근 구매 매장 우선

### F-06. 영수증 스캔 (P2 — Post-MVP)

- 카메라/Gallery에서 영수증 이미지 선택
- OCR로 품목·수량·가격·매장명 추출
- 사용자 확인 후 일괄 등록

## 비기능 요구사항

| 항목 | 요구 |
|------|------|
| 성능 | 벌집 50개 물품 기준 60fps 스크롤 |
| 오프라인 | 로컬 DB, 인터넷 없이 전 기능 동작 (MVP) |
| 데이터 | 기기 내 저장, 민감 정보 외부 전송 없음 |
| 접근성 | 최소 44pt 터치 영역, 색상 외 아이콘/텍스트로 상태 구분 |
| 알림 | 로컬 푸시 (flutter_local_notifications) |

## 제약 및 가정

- MVP는 **단일 사용자·단일 기기** 기준
- 물품 식별은 사용자가 지정한 이름 + 내부 ID (동명이물은 사용자가 병합)
- 통화/가격은 MVP에서 선택 사항 (이력용)
